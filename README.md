# Русский: пит-стоп

Тренажёр по русскому языку для 5–8 класса. Одна страница, никаких зависимостей, работает офлайн, прогресс сохраняется в браузере.

Идея простая: математика нравится, русский — нет. Поэтому каждое правило здесь подано не прозой из учебника, а деревом решений — идёшь по шагам сверху вниз, первое совпадение даёт ответ. Н/НН, НЕ с частями речи, ПРЕ-/ПРИ-, спряжение глаголов — всё это алгоритмы, и в таком виде они перестают быть зубрёжкой.

**Открыть:** https://USERNAME.github.io/russkiy-pitstop/

## Что внутри

184 карточки, 20 правил, четыре типа заданий:

| Тип | Что делает ученик |
|---|---|
| `choice` | Подставляет верное написание в пропуск |
| `theory` | Отвечает на вопрос про само правило |
| `comma` | Расставляет запятые кликом по тексту |
| `find` | Находит единственную ошибку в предложении |

Механики, которые удерживают за занятием 20–30 минут:

- **Интервальные повторения.** Ошибся — карточка вернётся завтра. Ответил верно несколько раз подряд — уйдёт на неделю, потом на месяц. Время тратится на то, что реально не выучено.
- **Ставка на уверенность.** Перед ответом можно поставить ×2. Верно — двойные очки, мимо — минус. Учит отличать «знаю» от «кажется».
- **Алгоритм по ошибке.** Ответил неверно — прямо под карточкой разворачивается блок-схема правила.
- **Карта правил** с прогрессом по каждой теме и серия дней подряд.
- **Блиц** на 10 карточек и **дуэль с родителем** на два счёта.

Примеры в карточках построены на Minecraft, Warhammer 40 000, NASCAR и технике — чтобы предложения не выглядели как из упражнения №214.

## Темы

**5–6 класс.** Приставки ПРЕ-/ПРИ- · Ы/И после приставок · приставки на З/С · чередующиеся гласные в корне · О/Ё после шипящих · сложные слова (соединительные О/Е, дефис, ПОЛ-) · суффиксы существительных (-ЕК/-ИК, -ЧИК/-ЩИК) · Ь после шипящих · правописание числительных · спряжение глаголов · суффиксы глаголов -ОВА-/-ЫВА- · -ТСЯ/-ТЬСЯ · прямая речь · НЕ с частями речи · дефис в местоимениях и наречиях

**7–8 класс.** Н и НН · причастный оборот · деепричастный оборот · производные предлоги · запятые: однородные, вводные, обращения, сложное предложение

## Как это устроено

```
src/app.html          вёрстка и движок; данные подставляются вместо /*DATA*/
src/01-cards-7-8.js   объявляет RULES и CARDS, наполняет их
src/02-cards-5-6.js   дополняет RULES и CARDS
build.py              склеивает всё в index.html
check.py              проверяет структуру карточек
deploy.sh             проверка + сборка + коммит + пуш одной командой
deploy.bat            то же самое для Windows
index.html            собранный файл, его же раздаёт GitHub Pages
```

`build.py` берёт все `src/*.js` **в алфавитном порядке имён** и вставляет в оболочку. Поэтому первый файл объявляет структуры, а остальные их дополняют.

## Добавить свои карточки

Самое полезное, что можно сделать с этим тренажёром, — загрузить в него реальные ошибки из школьных тетрадей. Создайте `src/03-moi-oshibki.js`:

```js
Object.assign(RULES, {
  moyo: {
    name: "Мои ошибки",
    idea: "Слова, на которых я реально спотыкаюсь.",
    steps: [
      "Здесь можно расписать разбор по шагам.",
      "Или оставить один пункт — правило всё равно откроется по кнопке."
    ]
  }
});

CARDS.push(
  {t:'choice', r:'moyo', q:'В инвентаре лежала ___ кирка.',
   o:['алмазная','алмазнная'], a:0, e:'Суффикс -Н- после основы на гласную.'},

  {t:'find', r:'moyo', w:['Он','зделал','всё','правильно.'],
   a:1, fix:'сделал', e:'Приставки З- в русском языке не бывает.'},

  {t:'comma', r:'moyo', w:['Кажется','мотор','заглох.'],
   a:[0], e:'«Кажется» — вводное слово.'}
);
```

Поля карточки:

- `t` — тип: `choice`, `theory`, `comma`, `find`
- `r` — id правила из `RULES`
- `q` — вопрос; для `choice` обязателен пропуск `___`
- `o` — варианты ответа, `a` — индекс верного (нумерация с нуля; порядок в приложении перемешивается)
- `w` — массив слов для `comma` и `find`
- для `comma`: `a` — массив индексов слов, **после** которых стоит запятая
- для `find`: `a` — индекс слова с ошибкой, `fix` — верное написание
- `e` — короткое объяснение, показывается после ответа

Дальше одна команда:

```bash
./deploy.sh "Добавил карточки из тетради"
```

На Windows — `deploy.bat "Добавил карточки из тетради"`. Сообщение можно не писать, тогда подставится дата.

Скрипт проверит карточки, пересоберёт `index.html`, закоммитит и запушит. Если в карточках ошибка — остановится и ничего не закоммитит, так что сломанную версию на сайт не выложить. Через минуту-две обновится и версия на Pages.

При желании те же шаги вручную:

```bash
python3 check.py    # проверит структуру
python3 build.py    # пересоберёт index.html
git add -A && git commit -m "Добавил карточки" && git push
```

## Локальный запуск

Отдельный сервер не нужен — достаточно открыть `index.html` двойным кликом.

Прогресс лежит в `localStorage` браузера, поэтому:

- заниматься нужно в одном и том же браузере;
- очистка данных сайтов обнулит статистику;
- локальный файл и версия на Pages ведут **раздельный** прогресс (у них разные origin).
